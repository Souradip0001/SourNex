Zero Prompt-Retention Protocol

Privacy Policy

Effective Date: November 21, 2026

1. Ephemeral Prompt Processing

Prompts and context memory blocks are processed transiently through our serverless proxy strictly to fulfill your active model request.

2. Local Browser Storage

Cached free-model metadata, and any optional provider API key you choose to supply are stored locally in your browser via localStorage. and sessionStorage.We Don't Store Your API in our database

3. Account & Authentication Data

If you register an account, your email and basic profile identity (including Google or GitHub OAuth sign-in) are managed through Auth0 Authentication solely for identity verification, session management, and password recovery.

4. Security & Abuse Prevention

Transient IP-based rate-limit counters and optional Cloudflare Turnstile verification tokens may be inspected in memory to prevent automated abuse and protect free-tier availability.
